## 1. One-Time Setup

### 1.1 AirSim settings.json

**CRITICAL — two gotchas that burned hours:**

**Gotcha 1 — Wrong path**: Windows redirects `Documents` to OneDrive.  
Real path: `C:\Users\akhil\OneDrive\Documents\AirSim\settings.json`  
(NOT `C:\Users\akhil\Documents\AirSim\settings.json`)

**Gotcha 2 — UTF-8 BOM**: PowerShell's `Set-Content -Encoding utf8` adds a BOM.  
AirSim's JSON parser rejects BOM → silently loads defaults → car dialog appears.

**Correct way to write settings.json (PowerShell):**
```powershell
$json = @"
{
  "SettingsVersion": 1.2,
  "SimMode": "Multirotor",
  "Vehicles": {
    "PX4": {
      "VehicleType": "PX4Multirotor",
      "UseSerial": false,
      "LockStep": true,
      "UseTcp": true,
      "TcpPort": 4560,
      "ControlPortLocal": 14540,
      "ControlPortRemote": 14580,
      "LocalHostIp": "127.0.0.1"
    }
  }
}
"@
$utf8NoBom = New-Object System.Text.UTF8Encoding $false
[System.IO.File]::WriteAllText(
    "$env:USERPROFILE\OneDrive\Documents\AirSim\settings.json",
    $json,
    $utf8NoBom
)
```

**Verify it loaded**: AirSim title bar shows `Loaded from OneDrive\Documents\AirSim\settings.json`  
If it shows the car dialog → BOM or wrong path.

### 1.2 WSL2 Mirrored Networking

**Problem**: WSL2 normally has its own `127.0.0.1` separate from Windows.  
PX4 sends MAVLink UDP to WSL2's loopback; Windows Python can't receive it.

**Fix** — create/edit `C:\Users\akhil\.wslconfig`:
```ini
[wsl2]
networkingMode=mirrored
dnsTunneling=true
```

Restart WSL2: `wsl --shutdown` then reopen.

Now WSL2 and Windows share the same `127.0.0.1` → DroneKit on Windows receives PX4 UDP from WSL2.

### 1.3 PX4 SITL Build in WSL2

**Problem — gz-harmonic protobuf conflict**: If Gazebo Harmonic is installed, PX4 build fails:
```
#error This file was generated by an older version of protoc which is incompatible
```

**Fix — remove gz-harmonic FIRST, then build:**
```bash
sudo apt remove -y gz-harmonic libgz-sim8-dev libgz-transport13-dev libgz-msgs10-dev
sudo apt autoremove -y
rm -rf build/px4_sitl_default
make px4_sitl_default none_iris
```

`none_iris` = runs without Gazebo, connects to AirSim via TCP 4560.

## 5. Troubleshooting — Errors We Hit and Fixed

### 5.1 AirSim shows car / "Waiting for TCP connection" but PX4 never connects
**Cause**: settings.json has BOM, or written to wrong path (Documents vs OneDrive\Documents).  
**Fix**: Use `New-Object System.Text.UTF8Encoding $false` + OneDrive path. See §1.1.

---

### 5.2 DroneKit "No heartbeat" / connection timeout
**Cause**: WSL2 UDP (port 14550) not visible to Windows — separate loopback.  
**Fix**: `networkingMode=mirrored` in `.wslconfig`. See §1.2.

---

### 5.3 PX4 build fails — protobuf/gz-harmonic conflict
```
#error This file was generated by an older version of protoc
```
**Fix**: Remove gz-harmonic before building. See §1.3.

---

### 5.4 `command 520 unsupported` spam in PX4 terminal
**Cause**: DroneKit sends `MAV_CMD_DO_SET_MODE` (command 520) which PX4 doesn't support.  
**Fix**: Use `mav.mav.set_mode_send()` directly instead of `vehicle.mode = VehicleMode(...)`.  
The spam is harmless noise — PX4 still responds to `set_mode_send`.

---

### 5.5 `Unsupported main mode` — OFFBOARD switch rejected
**Cause**: Wrong custom_mode value. We sent `6` but PX4 packs `main_mode` in **bits 16-23**.  
**Fix**: `custom_mode = 6 << 16 = 393216`
```python
mav.mav.set_mode_send(target_sys, MAV_MODE_FLAG_CUSTOM_MODE_ENABLED, 6 << 16)
```

---

### 5.6 DroneKit `APIException: mode (393216, 17) not available on mavlink definition`
**Cause**: DroneKit's HEARTBEAT handler doesn't know PX4 custom modes (ArduPilot-only).  
**Fix**: Drop DroneKit entirely for flight scripts. Use pure pymavlink.  
Background receiver thread reads HEARTBEAT + GLOBAL_POSITION_INT into a shared dict.

---

### 5.7 Armed then immediately auto-disarmed at alt=0.0m
**Cause**: Setpoint z=0 (ground) at arm time → PX4 sees no flight intent → auto-disarms.  
**Fix**: Set `_target_ned_z = -TARGET_ALT` **before** sending the arm command.
```python
_target_ned_z = -5.0   # go up 5m
time.sleep(0.3)         # let stream thread send new target
# THEN arm
```

---

### 5.8 `Already higher than takeoff altitude` / alt stays at 0.0m
**Cause**: EKF not stabilised immediately after SITL start.  
**Fix**: Wait 25 seconds after `Ready for takeoff!` before attempting flight.

---

### 5.9 `param types mismatch param: CBRK_SUPPLY_CHK`
**Cause**: DroneKit sends parameters as floats; PX4 expects integers for circuit-breaker params.  
**Fix**: Don't set PX4 parameters via DroneKit. Use force-arm magic number `21196` instead:
```python
MAV_CMD_COMPONENT_ARM_DISARM  param1=1  param2=21196
```

---

### 5.10 Battery failsafe triggers RTL during flight
**Cause**: SITL simulates missing power module → `system power unavailable` → failsafe.  
**Fix**: In PX4 pxh> shell: `param set COM_POWER_COUNT 0`

---

### 5.11 Python SyntaxError in sim_bridge.py — unicode escape
```
(unicode error) 'unicodeescape' codec can't decode ... \U
```
**Cause**: Windows path `C:\Users\akhil\...` in a docstring — `\U` treated as unicode escape.  
**Fix**: Use forward slashes in all docstring paths: `C:/Users/akhil/...`

## 6. Key Architecture Notes

### MAVLink Port Map
| Connection | Protocol | Port |
|---|---|---|
| AirSim ↔ PX4 physics | TCP | 4560 |
| PX4 → DroneKit / GCS | UDP | 14550 |
| PX4 onboard link | UDP | 14580 |

### NED Frame (PX4)
- x = North, y = East, z = Down
- **Negative z = up** → to climb 5m: `set_position_target_local_ned(z=-5.0)`

### PX4 Custom Mode Encoding
```
union px4_custom_mode { uint16_t reserved; uint8_t main_mode; uint8_t sub_mode; }
→ main_mode in bits 16-23 of the uint32 custom_mode field
```
| Mode | main_mode | custom_mode (Python) |
|---|---|---|
| MANUAL | 1 | `1 << 16` |
| POSCTL | 3 | `3 << 16` |
| AUTO/LOITER | 4 | `4 << 16` |
| OFFBOARD | 6 | `6 << 16` = 393216 |
| STABILIZED | 7 | `7 << 16` |

### PX4 OFFBOARD mode requirements
1. Stream `set_position_target_local_ned` at ≥2 Hz BEFORE switching to OFFBOARD
2. Set target altitude (non-zero z) BEFORE arming
3. Keep streaming continuously while airborne (stop → OFFBOARD exits)
